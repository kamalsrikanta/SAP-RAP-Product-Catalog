# RAP Source Object Inventory

This folder contains text representations of the RAP objects used by the project.

| Folder | Object |
|---|---|
| `database` | ZCJ_PRODUCT |
| `database` | ZCJ_PRODUCT_D |
| `cds` | ZCJ_I_PRODUCT |
| `cds` | ZCJ_C_PRODUCT |
| `behavior` | Behavior definition for ZCJ_I_PRODUCT |
| `behavior` | Projection behavior for ZCJ_C_PRODUCT |
| `behavior` | ZBP_CJ_I_PRODUCT implementation |
| `metadata` | ZCJ_C_PRODUCT metadata extension |
| `service` | ZCJ_PRODUCT_SRV |

The service binding `ZCJ_PRODUCT_UI` is maintained in ADT and is documented by the screenshots.
